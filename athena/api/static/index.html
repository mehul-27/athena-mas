                Architecture

                One supervisor in Google ADK plans, three researchers call MCP tools, and the analyst, writer and critic live in a separate CrewAI process reached over A2A. They share a blackboard, and every step is recorded as an event. Chat runs separately on a direct LLM call.

                Scroll horizontally to inspect the full architecture.

                  Tools (read-only)

                  Three MCP servers expose tools over stdio; the agents call them through the Model Context Protocol.

                  My documents

                  These are the documents in the local index. They stay on this computer. In Chat, turn on Documents to retrieve relevant passages for a message; when it is off, no document search runs.

                  Upload and personal document management are not implemented in this build. The indexed corpus is the source of truth; add files to data/corpus and rebuild from Settings → Library.

                  About

                  athena: Google ADK + CrewAI + A2A + MCP + a shared blackboard, with a separate direct-LLM Chat and a local Capillary background.

                  Old athena sections not carried over: Integrations/Email, Shortcuts, Account/Admin (no such features here), saved chat documents and Compact/PDF (no document or PDF pipeline in MAS), and arbitrary MCP server management (unsafe command execution).

                  Local use only. athena has no authentication; keep it bound to 127.0.0.1.
