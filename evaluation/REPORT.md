## How to produce the results

The crew A2A server must be up (`python scripts/dev_up.py`) before a live batch will start; the runner refuses to launch without it and reports why.

```
python scripts/dev_up.py
python -m evaluation.runner --dry-run
python -m evaluation.runner --out evaluation/results/<UTC timestamp>
python -m evaluation.analyze --results evaluation/results/<UTC timestamp>
python -m evaluation.report
```

Then rerun `python -m evaluation.report`: this file is regenerated from the records that exist at that moment.
